# Diário de bordo

Registro do projeto fase a fase: o que foi feito, por quê, o que deu errado e o que ficou de
aprendizado. Cada entrada termina com um **roteiro para o vídeo**, e o conjunto das entradas é a
base da apresentação final (Fase 7).

| Fase | Entrada | Versão | Data |
| --- | --- | --- | --- |
| 0 | [Fundação](fase-00-fundacao.md) | v0.1.0 | 2026-09-12 |

## Modelo de entrada

Todas as entradas seguem a mesma estrutura, para que a apresentação final possa comparar as fases
lado a lado:

1. **Objetivo**: o que a fase precisava entregar.
2. **O que foi feito**: entregas concretas, com links para commits e pull requests.
3. **Decisões**: ADRs criados e o motivo de cada um.
4. **Problemas e soluções**: o que deu errado e como foi resolvido.
5. **Resultados**: métricas, imagens e links.
6. **Roteiro para o vídeo**: o que mostrar e falar sobre a fase, em até dois minutos.
7. **Próximos passos**.
